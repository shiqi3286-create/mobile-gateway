个人移动聚合网关项目开发进度
==============================

一、项目概述
------------
项目名称：Android 个人移动聚合网关
当前仓库：https://github.com/shiqi3286-create/mobile-gateway
本地目录：E:\API聚合

项目目标：
在 Android 手机上运行一个个人移动聚合网关，将多个本地端口、第三方 API 和 AI 模型服务聚合到统一端口和统一管理 API。

当前网络模式：
- 电脑连接 Wi-Fi 并开启移动热点
- Android 手机连接电脑热点
- 手机网关监听 0.0.0.0:8080
- 电脑浏览器通过 http://手机IP:8080/admin 访问管理界面
- 手机不消耗移动数据，纯局域网运行

2. 路由管理

GET /api/routes
用途：获取路由列表。
可选参数：
- q：搜索路径或目标地址
- status：enabled/disabled
- page：页码
- page_size：每页数量

POST /api/routes
用途：创建路由。

PUT /api/routes/{id}
用途：修改路由。

DELETE /api/routes/{id}
用途：删除路由。

PATCH /api/routes/{id}/enabled
请求：
{"enabled": true}
用途：启用或禁用路由。

POST /api/routes/batch
用途：手机端多选后批量启用、禁用或删除。

POST /api/routes/{id}/test
用途：测试路由，返回请求、响应、耗时、Token 和协议转换结果。

POST /api/routes/{id}/pull-models
用途：测试连接并拉取上游模型列表。

路由对象：
{
  "id": "r_xxx",
  "path": "/user/*",
  "target": "http://127.0.0.1:9001",
  "proto": "openai",
  "proto_name": "OpenAI 兼容",
  "model": "gpt-4o-mini",
  "force": true,
  "method": "ALL",
  "timeout": 5000,
  "retry": 1,
  "qps": 50,
  "enabled": true,
  "adapt_ok": true,
  "keys": [
    {"key": "sk-...", "weight": 60, "name": "主力 Key"}
  ],
  "prompt": "系统提示词",
  "prompt_on": true,
  "cache": true,
  "cache_ttl": 300,
  "created_at": 0,
  "updated_at": 0
}

前端字段映射：
- route-path → path
- route-url → target
- route-proto → proto
- route-model → model
- route-force → force
- route-method → method
- route-timeout → timeout
- route-retry → retry
- route-qps → qps
- apikey-rows → keys
- route-prompt-sw → prompt_on
- route-prompt → prompt
- route-cache → cache
- route-cache-ttl → cache_ttl

手机端字段映射：
- rfPath → path
- rfTarget → target
- rfProto → proto
- rfForce → force
- rfModel → model
- rfKeysBtn → keys
- 高级设置中的系统提示词 → prompt
- 上下文缓存开关 → cache

用途：删除聚合接口。

请求：
{"enabled": true}
用途：启动或暂停聚合。

POST /api/aggregates/{id}/test
用途：执行非流式聚合测试。

GET/POST /api/aggregates/{id}/stream
用途：SSE 流式聚合测试。

聚合对象：
{
  "id": "a_xxx",
  "name": "用户订单聚合",
  "path": "/api/user/order",
  "method": "GET",
  "mode": "parallel",
  "enabled": true,

      "jsonpath": ""

  ],
  "mapping": "user: {$.steps[0].data}"
}

聚合步骤执行方式：
- parallel：并行
- serial：串行

步骤输出提取模式：
- auto：通用文本提取，自动适配平台响应
- jsonpath：使用自定义 JSONPath

十、重要注意事项
----------------

1. 当前两个 UI HTML 仍是静态原型，尚未真正接入 fetch 或 SSE。
2. 当前 Go 后端中的协议转换器和 ReverseProxy 仍是框架/占位阶段，不能当作生产网关使用。
3. seed 演示数据只用于联调，正式环境应关闭。
4. API Key 不应明文写入公开仓库；示例中的 Key 已脱敏。
5. 正式部署时应启用 API Key 鉴权和 IP 白名单。
6. `/api/*` 是管理接口命名空间，用户自定义路由应避免覆盖管理保留路径。
7. 当前 GitHub Actions 是云端验证的唯一编译入口，本地只进行文件和结构检查。
