Personal Mobile Aggregation Gateway
v0.9.1Apache-2.0
项目简介：在 Windows 电脑上运行的聚合网关。手机连接电脑开启的移动热点，网关监听 0.0.0.0:8080，聚合多个本地端口与第三方 API，供电脑局域网内通过浏览器访问管理。当前默认运行于电脑热点模式，手机不消耗移动数据。
功能：路径路由 · API 编排聚合 · 实时日志 · 流量统计 · BLE 广播 · API Key 鉴权 · IP 白名单。
Built on Windows 11 Fluent Design · Segoe UI
